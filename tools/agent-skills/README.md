# Repository Skills

Project-specific, opt-in workflows live here. The repository-wide agent instructions are in [`AGENTS.md`](../../AGENTS.md); do not repeat them in skills.

- [`validate-local-deploy`](./validate-local-deploy/SKILL.md) is only for explicitly requested Docker/prod-like verification. Its scripts are also used by existing tests.

Install a skill only for an agent runtime that supports it. Do not activate a local-deployment skill for routine code changes.
