从想到做到

知与行之间，只隔一次对话

MemoFlow 把 AI 对话放在你的计划旁边。聊出的决定，直接落到要做事的地方。

聊01

把念头说出来

AI 对话常驻在工作台一侧，读得到你在 MemoFlow 里的目标、任务和日程。

落02

落成具体的事

念头落成带关键结果的目标，和带检查清单的任务，彼此关联。

排03

排进日程

任务、日程和例程排进同一张周视图，到点提醒。

留04

做完留痕

完成状态、记录和关键结果的进度，都留在它所属的目标里。

产品界面

一个工作台，从对话到日程

下面每张截图都来自当前版本的 Web 端，会跟随你选的主题和语言切换。

左边聊，右边是今天

对话和你的一天并排放着，聊出的计划，转头就能在时间线上看到。

  • 今日时间线，已完成和待办一目了然
  • 今日例程，以及每个目标的进度
  • 可切换模型，也可设定 AI 能改动多少

可以度量的目标

把目标拆成关键结果：初始值、当前值、目标值。进度是算出来的，不靠感觉。

  • 按季度或年度设定周期和目标日期
  • 每个关键结果可设权重和计算方式
  • 关联的任务直接列在目标页

知道为什么要做的任务

每个任务都可以带上时间、检查清单，以及它服务的目标。

  • 单次、时间段、全天和重复任务
  • 检查清单直接显示在列表里
  • 按状态、标签和时间筛选

计划落到时间上

日程和带时间的任务放进同一张日历，这一周到底有多满，一眼就知道。

  • 日、周、月视图
  • 任务开始前按设定提醒
  • 通知集中在一处

给手头的事留出空间

该动手的时候，让业务面板占满整个窗口。

  • 一键进入或退出专注
  • 目标、任务、笔记和日程以标签页打开

能力

为“做到”而设计

常驻的 AI 对话

长期对话就在工作台旁边。Web 端使用内置助手；桌面端还可以选择本机的 Codex、Claude Code 或 Pi 等智能体。

改什么，由你决定

每个对话都有权限档位。“需要确认”会在需要权限的操作前逐次询问你。

只读需要确认自动批准

目标与关键结果

可度量的关键结果、权重与记录，任务可以绑定到它推动的那条结果上。

任务、清单与重复

时间段、全天和重复规则，每个任务都能有检查清单和重要程度。

日程、例程与提醒

日程、定时任务和每天的例程同在一张日历，配上提醒和通知中心。

Web 与桌面端

Vue Web 和 Electron 桌面端共用同一套业务契约，PowerSync 负责跨设备的数据同步。

工程

边界先写清，再由机器守住

业务模块各自拥有状态、契约和权限。架构决策有记录，规则由 CI 检查。

121份架构决策记录（ADR）
71个工作区包
2个客户端：Web 与桌面端
  • 业务归属Goal、Task、Schedule、Repository 等模块各自拥有状态、权限与传输。
  • AI 写入路径类型化工作流，加上写入前的明确批准。
  • 多端数据PostgreSQL、PowerSync，以及明确的离线与缓存策略。
  • 质量门禁Nx affected 目标、治理检查、单元与集成测试，以及 Playwright 端到端测试。
