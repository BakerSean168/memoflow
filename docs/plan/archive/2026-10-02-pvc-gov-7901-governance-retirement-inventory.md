# PVC-GOV-7901 — Product Governance retirement inventory

## Decision gate

ADR-113 is still **Proposed / awaiting final confirmation**. Therefore this ticket is strictly
non-destructive. GOV-7903 cannot run and no Product Governance runtime/package/schema/UI removal is
allowed.

## Inventory objective

Enumerate every dependency surface that would be affected if ADR-113 is later accepted, classify
each reference group exactly once, and identify the smallest `MIGRATE_FIRST` set required for
GOV-7902.

Classification:

- `RETIRE` — Product Governance runtime/reference-feature only.
- `KEEP_ENGINEERING` — deterministic repository engineering governance that survives.
- `SHARED` — legitimate shared infrastructure/primitive requiring explicit owner decision.
- `MIGRATE_FIRST` — currently couples Engineering Governance or another surviving owner to Product
  Governance and must be decoupled before destructive retirement.

## Required surfaces

- contracts/public exports/RPC;
- packages/governance domain/application/infrastructure/API/client/electron;
- app-vue routes/DI/UI/query keys/i18n;
- Prisma/database/migrations/seeds;
- PowerSync schema/sync/client projections;
- API and Desktop composition/IPC/preload;
- Nx/build/docker/runtime manifests and environment;
- tests/fixtures/E2E/smoke/architecture locks;
- tools/governance and its rule-bundle inputs;
- AGENT/CLAUDE/copilot/product/architecture docs;
- analytics/export/data portability dependencies.

## Method

1. Repo-wide symbol/path grep for `governance`, `Rule`, `RuleRevision`, governance bundle contracts,
   product route/module keys and engineering bundle adapters.
2. Inspect dependency direction at composition roots rather than classifying by filename alone.

4. Define GOV-7902 from concrete `MIGRATE_FIRST` blockers.
5. Record GOV-7903 zero-reference queries, but do not execute retirement.

  reading both classified and unclassified files, including historical/report exemptions.

  Rule IDs/status/severity/DTOs, RuleRevision/model references and SQL `rules` table contexts now
  fail when unclassified; generic binary `governance` prose and generic `rule`/`rules` variables
  remain non-blocking. Known text and binary patterns are protected against weakening.

  enumerates live Git files and checks exact-path resolution and drift together.
- The bundle bridge group previously labeled hand-written tests as fixtures. Its default marker is
  now source; the JSON fixture has an explicit fixture path marker. The mock regression test also
  has a source path marker within its fixture group. Each marker independently validates
  `sourceOfTruth`; override keys must belong to that group's exact paths.
- All seven migration groups now require their B1–B6 mapping. Product-only JSDoc tools, mock files,
  locales and dedicated composers/tests cannot be relabeled KEEP_ENGINEERING. Duplicate ownership,
  malformed paths/metadata and generated Prisma misclassification remain fail-closed.
- Live path validation preserves legitimate unrelated Git filenames such as mobile `[id].tsx`
