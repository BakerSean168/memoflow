# PVC-TASK-3301A

1. Add the runtime-owned Fixed/Prompt progress rule; normalize legacy contribution and reject conflicts. Domain and portability consume the canonical rule; contribution is derived.
2. Persist explicit mode/suggestion columns in Prisma and PowerSync, with legacy Fixed decoding and a revised database invariant. Generate Prisma through its Nx target.
3. Validate Fixed against Goal-owned KR measurement context through a bounded read port in create/update and binding commands. Preserve owner and identity boundaries.
4. Project Goal DTO measurement and Goal-owned presentation labels into Task options. Add three form modes, signed Fixed values, optional finite suggestions, deterministic Fixed-to-Prompt transition for non-Sum KRs, and Goal-only LinkOnly.
5. Verify contracts, domain, use cases, persistence, portability, UI, existing automatic settlement, typechecks, generation, changed-file lint, governance, and diff whitespace. Completion commands/dialogs and Prompt outbox remain outside scope.

## Result

Completed PVC-TASK-3301A only. Task uses canonical Fixed/Prompt progressRule; the deprecated contribution mirror is derived and conflicting writes fail. Goal-owned KR context and localized presentation drive the three form modes. Prompt persists suggestions without creating automatic progress facts. Signed Fixed deltas remain on the existing settlement path. No completion measurement command/dialog, Goal mutation, Schedule/AI changes, route/ID changes, commit, or push.

The public object schema keeps its existing `.strict()` API through Zod overwrite, while canonical read DTOs infer required normalized fields from the shared configuration schema. Legacy contribution-only inputs and rows decode into Fixed. Prompt suggestions normalize missing values to null so persistence and portability replay compare the same semantic state.
