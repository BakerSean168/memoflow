# PVC-TASK-3301B

1. Extend the shared completion request and authoritative completion event with sanitized optional measurement intent; validate persisted Prompt configuration before mutation.
2. Derive explicit FixedAutomatic / PromptedUserMeasurement V2 outbox events in the existing Task transaction; normalize legacy V2 payloads in the dispatcher.
3. Select Goal-owned authorship and notes in the consumer, preserving source uniqueness and aggregation.
4. Characterize contracts, completion, outbox, dispatcher, both transaction adapters, Goal replay and transport/client parity. Run focused tests, Task/Goal typechecks, changed-file lint, diff and governance checks.

Scope: TASK-3301B only; no UI, migration, route/ID changes, Task-side Goal writes, commit or push.

## Result

Implemented TASK-3301B only. The shared request accepts finite measurements including zero/negative, with a distinct optional/null Goal note (max 500). The command validates the persisted Prompt KR binding before mutation and sanitizes intent. The authoritative event feeds the existing Prisma/PowerSync transaction runners; no second write path was added. New apply events explicitly carry FixedAutomatic or PromptedUserMeasurement; the decoder normalizes persisted V2 events without recordingMode to FixedAutomatic. Prompt requires a TaskOccurrence source. Goal selects TaskUserMeasurement and the user note; Fixed retains TaskAutomatic and generated notes. Source uniqueness and replay remain authoritative; Goal owns all aggregation. No frontend production code, UI dialog, migration, public route/ID change, commit or push.

Runtime ownership: TaskGoalMeasurementSchema lives in Task value objects and is shared by the command and durable decoder. Recording mode is a Task-owned const/type. Completion event context derives its shape from the authoritative event. HTTP/IPC and Web/Desktop adapters continue to use CompleteTaskOccurrenceSchema/Req. No Task-owned Goal repository reads or writes were added.
